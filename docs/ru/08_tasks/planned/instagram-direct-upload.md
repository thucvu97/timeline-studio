# Прямая загрузка видео в Instagram

## Описание задачи

Добавить возможность прямой загрузки видео в Instagram из Timeline Studio, используя пакет `instagram-private-api`. Это позволит пользователям публиковать контент напрямую без необходимости ручной загрузки.

## Цель

Расширить функциональность экспорта в социальные сети, добавив Instagram к существующим платформам (YouTube, TikTok, Vimeo, Telegram).

## Технические требования

### 1. Установка зависимостей
```bash
bun add instagram-private-api
bun add re2 # для безопасности (CVE-2020-7661)
```

### 2. Создание InstagramService
- Путь: `/src/features/export/services/instagram-service.ts`
- Функциональность:
  - Аутентификация (login/logout)
  - Загрузка видео в ленту
  - Загрузка Reels
  - Загрузка Stories
  - Обработка ошибок и rate limiting

### 3. Интеграция с существующей системой
- Добавить Instagram в `SOCIAL_NETWORKS` в `/src/features/export/constants/export-constants.ts`
- Обновить `SocialNetworksService` для поддержки Instagram
- Добавить UI элементы в `SocialExportTab`

### 4. Форматы и ограничения

#### Для ленты (Feed):
- Формат: MP4 или MOV
- Максимальный размер: 100MB
- Длительность: до 60 минут
- Соотношение сторон: 16:9, 1:1, 4:5
- Минимальное разрешение: 600x600

#### Для Reels:
- Формат: MP4 или MOV
- Максимальный размер: 15MB
- Длительность: 15-90 секунд
- Соотношение сторон: 9:16
- Разрешение: 1080x1920 (рекомендуется)

#### Для Stories:
- Формат: MP4 или MOV
- Максимальный размер: 4GB
- Длительность: до 60 секунд
- Соотношение сторон: 9:16
- Разрешение: 1080x1920

### 5. Функции безопасности
- Хранение учетных данных в зашифрованном виде
- Поддержка двухфакторной аутентификации
- Обработка капчи
- Опциональная поддержка прокси

### 6. UI/UX требования
- Выбор типа публикации (Feed/Reels/Stories)
- Предпросмотр с правильным соотношением сторон
- Индикатор прогресса загрузки
- Предупреждение о рисках использования неофициального API

## Риски и ограничения

⚠️ **Важно**: Использование приватного API Instagram нарушает их условия использования и может привести к:
- Временной или постоянной блокировке аккаунта
- Ограничению функциональности
- Необходимости прохождения проверок безопасности

## Альтернативные решения

1. **Instagram Basic Display API** (официальный)
   - Только чтение данных, не поддерживает загрузку
   
2. **Instagram Graph API** (для бизнес-аккаунтов)
   - Ограниченная функциональность
   - Требует Facebook Business аккаунт
   - Сложный процесс получения разрешений

3. **Интеграция через Buffer/Hootsuite API**
   - Использование сторонних сервисов планирования
   - Дополнительные затраты
   - Более надежно, но менее удобно
