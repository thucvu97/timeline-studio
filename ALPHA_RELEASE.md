# Timeline Studio - Alpha Release v0.60.0

## 🚀 Быстрый старт

```bash
# 1. Установить Ollama (для AI функций)
# macOS
brew install ollama

# Linux  
curl -fsSL https://ollama.ai/install.sh | sh

# 2. Скачать модель
ollama pull llama3.2

# 3. Запустить Ollama
ollama serve

# 4. В новом терминале запустить Timeline Studio
bun install
bun run tauri dev
```

## 📋 Что работает в альфе

### ✅ Базовый функционал
- Timeline редактор
- Медиа браузер  
- Video player
- Проекты и сохранение

### 🤖 AI функции (через Ollama)
- Анализ видео контента
- Детекция сцен
- Генерация субтитров
- Экспорт результатов в JSON

### ⚠️ Ограничения
- Только локальные AI модели (бесплатно)
- Базовая точность анализа
- Нет GPU ускорения
- ~300+ TypeScript ошибок (не влияют на работу)

## 🧪 Тестовые сценарии

### 1. Простой анализ видео
1. Загрузить видео < 5 минут
2. Открыть AI Content Intelligence
3. Нажать "Анализ"
4. Дождаться результатов
5. Экспортировать в JSON

### 2. Генерация субтитров
1. Загрузить видео с речью
2. Использовать AI для транскрипции
3. Сгенерировать субтитры
4. Экспортировать в SRT

## 🐛 Известные проблемы

1. **Первый запрос медленный** - Ollama загружает модель в память
2. **TypeScript ошибки** - Не влияют на функциональность
3. **Нет стриминга** - Ответы AI приходят целиком

## 📦 Рекомендуемые модели Ollama

| Модель | Размер | Описание |
|--------|--------|----------|
| qwen2.5:0.5b | 400MB | Самая быстрая для тестов |
| gemma2:2b | 1.6GB | Оптимальный баланс |
| **llama3.2** | **2GB** | **Рекомендуется** |
| phi3 | 2.3GB | Microsoft, хорошая производительность |
