# AI Chat Services

Этот каталог содержит сервисы для работы с AI чатом и интеграции различных AI-провайдеров в Timeline Studio.

## Список сервисов

### Основные AI провайдеры

- **`claude-service.ts`** - Интеграция с Claude API от Anthropic. Поддерживает модели Claude 4 Opus и Sonnet, включая работу с инструментами.

- **`open-ai-service.ts`** - Интеграция с OpenAI API. Поддерживает модели GPT-4, GPT-4 Vision и GPT-3.5 Turbo.

- **`deepseek-service.ts`** - Интеграция с DeepSeek API для работы с их языковыми моделями.

- **`ollama-service.ts`** - Интеграция с локальными моделями через Ollama для работы без интернета.

### Специализированные сервисы

- **`unified-ai-service.ts`** - Унифицированный интерфейс для работы со всеми AI провайдерами. Автоматически выбирает подходящий провайдер и обрабатывает запросы.

- **`timeline-ai-service.ts`** - AI сервис для работы с таймлайном, включая интеллектуальный монтаж, анализ контента и генерацию рекомендаций.

- **`whisper-service.ts`** - Сервис для транскрипции аудио с использованием OpenAI Whisper API. Поддерживает множество языков и форматов.

- **`ffmpeg-analysis-service.ts`** - Анализ видео файлов с помощью FFmpeg для извлечения метаданных и технических характеристик.

- **`multimodal-analysis-service.ts`** - Мультимодальный анализ контента (видео + аудио + текст) для комплексного понимания материала.

### Вспомогательные сервисы

- **`api-key-loader.ts`** - Управление API ключами для различных сервисов. Безопасное хранение и загрузка ключей из настроек пользователя.

- **`chat-storage-service.ts`** - Сохранение и загрузка истории чатов, управление сессиями.

- **`batch-processing-service.ts`** - Пакетная обработка множества файлов с использованием AI инструментов.

- **`platform-optimization-service.ts`** - Оптимизация контента для различных платформ (YouTube, TikTok, Instagram).

- **`workflow-automation-service.ts`** - Автоматизация рабочих процессов и создание пайплайнов обработки.

- **`intent-recognition.ts`** - Распознавание намерений пользователя для выбора подходящих инструментов и действий.

### State Management

- **`chat-machine.ts`** - XState машина состояний для управления чатом, сообщениями и сессиями.

- **`chat-provider.tsx`** - React Context Provider для доступа к функциональности чата во всем приложении.

### Экспорты

- **`index.ts`** - Главный файл экспорта всех публичных сервисов модуля.

## Использование

```typescript
// Импорт отдельного сервиса
import { ClaudeService } from './claude-service'

// Импорт унифицированного сервиса
import { UnifiedAIService } from './unified-ai-service'

// Использование провайдера чата
import { ChatProvider, useChat } from './chat-provider'
```

## Тестирование

Каждый сервис имеет соответствующие тесты в директории `__tests__/services/`. Моки для тестирования находятся в `__mocks__/`.
