# Модуль Video Player

[English](./README.md) | **Русский**

## 📋 Обзор модуля

Модуль Video Player предоставляет комплексную функциональность воспроизведения видео с поддержкой различных форматов, предпросмотра эффектов, переходов, HDR-контента и полной интеграцией с экосистемой Timeline Studio. Модуль использует архитектуру машины состояний для надежного управления воспроизведением и интегрируется с Tauri для десктопной функциональности.

## 🔧 Техническая реализация

### Архитектура
- **XState Machine**: Надежное управление состоянием для воспроизведения
- **React Context**: Глобальный доступ к состоянию плеера
- **Custom Hooks**: Переиспользуемые логические компоненты
- **TypeScript**: Полная типобезопасность
- **Интеграция с Tauri**: Доступ к файлам на десктопе и конвертация URL

### Интеграция с Tauri
```typescript
// Конвертация путей для десктопного приложения
import { convertVideoSrc } from "@/lib/tauri-utils"

// Синхронизация с backend
import { getBackendSync } from "@/features/app-state/services/backend-sync"
```

### Backend команды
- `Play`: Начать воспроизведение
- `Pause`: Поставить на паузу
- `Seek`: Перейти к позиции
- `SetPlaybackRate`: Изменить скорость
- `playerSetMedia`: Загрузить медиа
- `playerSetVolume`: Установить громкость
- `playerSelectClip`: Выбрать клип
